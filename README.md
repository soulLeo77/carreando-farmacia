-- Para iniciar el proyecto, haga lo siguiente en la terminal
1. Base de datos
* Puede utilizar XAMPP o cualquier otra herramienta que le proporcione acceso a una base de datos MySql
- Creé su base de datos con el nombre de su preferencia (tendrá que incluir sus configuraciones en el archivo *.env* ubicado dentro de la carpeta **backend**).
- Con su base de datos creada ejecute el código sql que esta dentro del archivo *db.txt* ubicado en la raíz del proyecto.

2. Backend
* Abra una terminal en la raíz del proyecto.
- cd Backend
- npm install
- node server.js

3. Fronted
* Ubiquese nuevamente en la raíz del proyecto
- cd frontend
- npm install
- npm run dev
* Ahora dirijase a la URL que se le proporcionó luego de ejecutar el último comando.
